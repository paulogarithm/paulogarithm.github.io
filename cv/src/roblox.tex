\underline{\bfseries cclass -- Runtime Memory Mutation Engine} (\href{https://github.com/paulogarithm/cclass}{link})
\par
\begin{adjustwidth}{5pt}{0pt}
    Parses the process's own compiled binary at runtime and uses \texttt{nm} symbol lookups to compute exact function sizes. \\
    Copies raw function bytes into an executable memory page (via {\bfseries \texttt{mmap}}) allocated directly after each object instance. \\
    Reserves the last 8 bytes before the copied function's end as a hidden slot for the object pointer, read by the function itself as an implicit \texttt{this} -- emulating method dispatch without a vtable.
\end{adjustwidth}

{\bfseries Skills:} C, Linux Systems, x86 Assembly, mmap, Memory Safety, Low-level Debugging
